# وثيقة الشرح والتوجيه المعماري الشامل لبناة الذكاء الاصطناعي (Prompt Architecture & Technical Explanation)

تهدف هذه الوثيقة إلى تفكيك وشرح الهيكل المعماري والقرارات الهندسية والتصميمية لتطبيق **"أوتاكو ساما | Otaku Sama"**، لتمكين أي محرك أو أداة ذكاء اصطناعي (مثل Claude, GPT-4, Cursor, v0, Bolt, Lovable) من فهم المتطلبات وتطبيقها بأعلى درجات الدقة دون أي حيود (Zero-Drift Execution).

---

## 1. الفلسفة المعمارية ونظام التدويل الثنائي (Bilingual Dynamic System & RTL/LTR)

### أ. إدارة الاتجاهات واللغات (Strict Logical Properties Mandate):
* **القاعدة الذهبية:** يُمنع منعاً باتاً استخدام الاتجاهات الفيزيائية في CSS (مثل `left`, `right`, `ml`, `mr`, `pl`, `pr`).
* **الاستبدال الإلزامي بالخصائص المنطقية:**
  - `start` بدلاً من `left` في اللغة الإنجليزية، و`right` في اللغة العربية.
  - `end` بدلاً من `right` في الإنجليزية، و`left` في العربية.
  - استخدام فئات Tailwind المنطقية حصراً:
    - `ms-` (Margin Inline Start)
    - `me-` (Margin Inline End)
    - `ps-` (Padding Inline Start)
    - `pe-` (Padding Inline End)
    - `border-s-` و `border-e-`
* **المزامنة الديناميكية:**
  عند تغيير اللغة، يتم فوراً تحديث خصائص جذر المستند (`document.documentElement`):
  ```typescript
  document.documentElement.dir = lang === 'ar' ? 'rtl' : 'ltr';
  document.documentElement.lang = lang;
  ```
  هذا يضمن انقلاب واجهات المستخدم وتدفق النصوص والقوائم والأيقونات بسلاسة طبيعية ودون تشوه بصري.

## 2. فلسفة التصميم ومكافحة القوالب النمطية (Anti-Slop & Luxe Pro UI/UX)

1. **الهدوء البصري والمساحات التنفسية (Distill & Rhythm):**
   - تم استبدال الكروت المبعثرة بقوائم مجمعة حديثة ذات فواصل شفافة خفيفة (`border-white/10`).
   - الالتزام بنظام شبكة 8pt للمسافات الداخلية والخارجية (`p-4`, `p-6`, `gap-3`).
2. **منع التباينات الحادة والألوان المبتذلة:**
   - تم تجنب التدرجات الأرجوانية التقليدية المبتذلة (AI Generic Gradients) واستبدالها بلوحة ألوان داكنة نيون مستوحاة من ثقافة السايبربانك اليابانية الفاخرة (`#0B0B18`).
   - النصوص الرئيسية باللون الأبيض النقي مع توهج خفيف، والنصوص الثانوية بدرجات الرمادي الفضي المتوازن (`text-slate-300` و `text-slate-400`).
3. **تجربة الهواتف أولاً (Mobile-First Touch Targets):**
   - مساحات النقر لكافة الأزرار وعناصر التحكم لا تقل عن `44px × 44px` لضمان سهولة الاستخدام باللمس.
   - حقول الإدخال ذات ارتفاع موحد وحواف مضيئة واضحة عند التركيز (`focus:ring-2 focus:ring-[#7C5CFF]`).
4. **العناوين والنصوص المقاومة للانقسام:**
   - تطبيق `whitespace-nowrap` على اسم التطبيق لتفادي أي انقسام مزعج للكلمات على شاشات الهواتف الضيقة.

## 3. محرك الشعار الرسمي (Dual-Engine Brand Crest)

يتكون شعار "أوتاكو ساما" من عناصر هندسية ذات دلالات عميقة:
1. **حلقة النيون الخارجية والدرع السداسي:** تعبر عن قوة وحماية المجتمع الرقمي للأوتاكو.
2. **بتلات الساكورا الثلاث (اليسار):** ترمز لأصالة الثقافة اليابانية وعالم الأنمي الكلاسيكي، وتتميز بالشق الترويسي في طرف كل بتلة.
3. **كانجي 様 والدوائر المطبوعة (اليمين):** يجمع بين التبجيل والشرف (ساما) مع خطوط الدوائر الإلكترونية والعُقد المسدسة التي ترمز لمستقبل الألعاب والسايبر.
4. **آلية التحميل المزدوجة (Dual-Asset Engine):**
   - **الطبقة الأولى (Image First):** يحاول التطبيق قراءة ملف الصورة الأصلي المرفوع فور وضعه في المجلد العام (`/otaku_sama_brand_mark.png` أو `/logo.png`).
   - **الطبقة المتجهية الاحتياطية (Crisp SVG Fallback):** في حال عدم وجود ملف الصورة النقطية، يعرض التطبيق رسماً متجهياً متناظراً بدقة إحداثيات مطلقة خالية من أي ضبابية أو تشوه لتوفير تجربة بصرية فائقة الوضوح.

## 4. محرك الصوت الرقمي لسيف الكاتانا (Web Audio API Synth Engine)

لتجنب الاعتماد على ملفات صوتية خارجية ضخمة قد تفشل في التحميل، تم تصميم سينث صوتي مدمج وخفيف جداً باستخدام **Web Audio API**:
```typescript
const playKatanaSlash = () => {
  const audioCtx = new (window.AudioContext || window.webkitAudioContext)();
  const osc = audioCtx.createOscillator();
  const gain = audioCtx.createGain();

  // تدرج ترددي سريع يحاكي سحب وشق نصل السيف في الهواء
  osc.type = 'sine';
  osc.frequency.setValueAtTime(420, audioCtx.currentTime);
  osc.frequency.exponentialRampToValueAtTime(120, audioCtx.currentTime + 0.12);

  // تدرج الصوت ليتلاشى خلال 140 مللي ثانية
  gain.gain.setValueAtTime(0.08, audioCtx.currentTime);
  gain.gain.exponentialRampToValueAtTime(0.001, audioCtx.currentTime + 0.14);

  osc.connect(gain);
  gain.connect(audioCtx.destination);
  osc.start();
  osc.stop(audioCtx.currentTime + 0.15);
};
```

## 5. هيكلية المكونات ومسؤولياتها (Component Hierarchy)

* **`App.tsx`:** إدارة الحالة المركزية (التبويب النشط، اللغة، تفعيل النيون، تفعيل الصوت، فتح وإغلاق النوافذ).
* **`Header.tsx`:** ترويسة علوية نظيفة تحتوي على الشعار واسم التطبيق وأزرار الإعدادات والإشعارات بدون أي عناصر دخيلة مثل أزرار الـ VIP.
* **`KatanaBottomNav.tsx` & `KatanaSwordGraphic.tsx`:** تجسيد نصل سيف الكاتانا الياباني الفولاذي مع نقاط ارتكاز التبويبات الخمسة وتأثيرات القطع الضوئية.
* **`SettingsDrawer.tsx`:** القائمة الجانبية المجمعة لضبط الحساب، اللغات، الكاش، ومودالات "حول التطبيق" والخصوصية.
* **`AuthModal.tsx`:** نافذة تسجيل الدخول الآمنة مع واجهات الاستكشاف كزائر.
* **`ProfileSection.tsx`:** بطاقة الهوية الرقمية للمحارب مع الختم المائي والعلامة الموثقة.
